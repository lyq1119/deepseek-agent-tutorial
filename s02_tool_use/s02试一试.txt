The two chapters present so far are:

**s01: The Agent Loop — "One Loop Is All You Need"**
- The core concept: a `while True` loop that keeps the model acting. When the model calls a tool (`stop_reason == "tool_use"`), the harness executes it and feeds the result back; when it stops calling tools, the loop exits.
- The model only has **one tool: bash** (run shell commands).
- The minimal agent harness kernel is under 30 lines.

**s02: Tool Use — "Add a Tool, Add Just One Line"**
- Extends s01 from 1 tool to **5 tools**: `bash`, `read_file`, `write_file`, `edit_file`, `glob`.
- Introduces a `TOOL_HANDLERS` dispatch map, replacing the hard-coded `run_bash` call. Adding a tool = one entry in the `TOOLS` array + one line in the dispatch dict.
- Adds `safe_path` validation so file tools stay inside the workspace, and a small guard blocking dangerous bash commands.
- Supports multiple tool calls in one response, executed in order.

The project includes runnable `code.py` scripts (an interactive REPL), READMEs in English/中文/日本語, architecture SVG diagrams, a `.env` for the DeepSeek API key, and `requirements.txt` (`openai`, `python-dotenv`). The roadmap mentions future chapters like s03 "Permission" (adding approval gates before tool execution).
