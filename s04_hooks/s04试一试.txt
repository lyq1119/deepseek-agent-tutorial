## README.md Summary

**Learn DeepSeek Agent Tutorial — Harness Engineering for Real Agents**

This repository is a DeepSeek adaptation of the `learn-claude-code` tutorial, using DeepSeek's OpenAI-compatible API:
```
DEEPSEEK_API_KEY + https://api.deepseek.com + deepseek-v4-flash
```

### Core Concepts
- **Agent Product = Model + Harness** — the model supplies intelligence; the harness supplies the environment (tools, observations, permissions, extension points)
- **Agent Pattern**: `User → messages[] → LLM → tool calls?` (execute tools → append results → loop, or return final text)
- Provides a Python `agent_loop()` implementation showing the core loop with `client.chat.completions.create()`, tool call dispatch via `TOOL_HANDLERS`, and tool result appending

### Setup
```sh
pip install -r requirements.txt
cp .env.example .env
# Edit .env and set DEEPSEEK_API_KEY
```
Default model: `deepseek-v4-flash`. Never commit `.env`.

| Lesson | Topic | Adds |

| s01 | Agent Loop | One loop and one Bash tool |
| s02 | Tool Use | Five tools + `TOOL_HANDLERS` dispatch |
| s03 | Permission | Deny list, risk rules, user approval |
| s04 | Hooks | Extension points before/after tool execution |

Run from repo root: `python s01_agent_loop/code.py`, etc.
